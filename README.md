# Inventory Management System

A Laravel-based Inventory Management System for storing the billing.

## Technologies Used

- Laravel
- PHP
- MySQL
- Bootstrap
- JavaScript
- jQuery

## Installation

1. Clone the repository

   git clone https://github.com/giridharan11032002/Inventory-system.git
   
   2. Go to the project directory

   cd Inventory-system

3. Install dependencies

   composer install
   4. Configure the database in `.env`
   

5. Run migrations

   php artisan migrate
